STUDY QUEST II — 움직이는 캐릭터 에디션
========================================

실행: index.html을 더블클릭하세요. 설치/npm/API 키 없이 오프라인으로 실행됩니다.

새 기능
- 전투 화면에서 키보드 ← ↑ ↓ → 또는 WASD로 마법사 이동
- 전투 화면 아래 방향 버튼을 클릭하거나 꾹 눌러 이동 (모바일 터치 지원)
- 정답을 맞히면 캐릭터가 몬스터 앞으로 돌진하며 공격 이펙트 표시
- 오답 시 캐릭터 피격 반응 유지
- 몬스터 전투, 콤보, XP, 골드, 레벨업, 오답 복습, 문제 JSON 가져오기 모두 유지
- 1~4 키는 객관식 선택, Enter 키는 다음 문제

주의: 이동은 화면 연출용이며, 문제를 맞혀야 몬스터가 피해를 받습니다.
게임 진행 기록은 브라우저에 자동 저장되며 이전 디럭스 버전과 저장 키를 공유합니다.
캐릭터 위치는 저장되지 않고 페이지를 새로고침하면 처음 위치에서 시작합니다.

STUDY QUEST II — ACADEMY DUNGEON
================================

1. 실행하기
----------
압축을 풀고 study-quest-deluxe 폴더의 index.html을 더블클릭하세요.
Chrome 또는 Edge에서 바로 실행됩니다.

npm install, npm start, API 키, .env, 인터넷 연결이 필요하지 않습니다.

2. 준비된 문제
--------------
컴퓨터구조 9주차 강의 자료로 만든 문제 2세트가 들어 있습니다.
- 핵심편: 개념+상황형 10문제
- 응용편: 이진 선택선·레지스터·주소형식·시프트 계산 10문제
각 문제에 설명, 힌트, 강의 자료 페이지가 포함됩니다.

처음 열면 핵심편이 자동으로 시작됩니다. 왼쪽에서 응용편으로 바꿀 수 있습니다.

3. 게임 방법
------------
- 답을 클릭하거나 키보드 숫자 1~4로 고릅니다.
- 정답이면 몬스터에게 30의 피해, EXP +18, GOLD +8.
- 3연속 정답부터 추가 피해 +10, 5연속부터 추가 피해 +20.
- 몬스터 처치 시 EXP +25, GOLD +20.
- 오답이면 에너지 -15 (0이 되면 60으로 회복), 오답 노트에 저장.
- 10문제를 완료한 뒤 오답 다시 풀기로 복습할 수 있습니다.
- 진척/성장 상태는 이 브라우저에 자동 저장됩니다.
- 오른쪽 위 ♪ OFF 버튼으로 효과음을 켜고 끌 수 있습니다.

4. 내 자료로 문제를 만들려면
---------------------------
PDF 파일은 게임에서 직접 업로드하지 않습니다.
ChatGPT 채팅에 PDF를 보내서 쉬운/응용 객관식 10문제 JSON을 받아야 합니다.
그다음 왼쪽 '+ 내 문제 불러오기'를 열고 JSON 파일을 선택하거나 내용을 붙여넣습니다.

호환 형식 예시:
{"title":"제목","questions":[{"question":"질문","options":["보기1","보기2","보기3","보기4"],"answerIndex":0,"explanation":"왜 정답인지 설명","topic":"CPU","sourcePage":15,"hint":"힌트","skill":"적용"}, ...]}
- questions는 정확히 10개
- answerIndex는 0~3 (첫 번째 보기 = 0)
- topic/sourcePage/hint/skill 필드는 생략 가능

5. 보안 및 주의
--------------
- 서버와 API 없이 작동하고, 게임이 학습 PDF/문제를 외부 서버로 전송하지 않습니다.
- 문제가 포함된 JSON 파일을 다른 사람과 공유할 때 강의 자료의 이용 조건을 확인하세요.
- 진행 상황은 브라우저의 localStorage에 저장됩니다. 브라우저 저장소를 지우면 사라질 수 있습니다.
- 이전 버전의 저장 기록은 자동 이관되지 않습니다.
- PDF 페이지 번호는 제공된 강의 자료 기준입니다.

스터디 퀘스트 — API 키/서버 필요 없는 버전
======================================

[실행]
1. 이 폴더의 index.html 파일을 더블클릭합니다.
2. 크롬에서 게임이 열립니다. npm install/npm start는 절대 필요하지 않습니다.
3. '예시 문제 10개로 체험' 버튼을 눌러 바로 테스트할 수 있습니다.

[본인 PDF로 문제 만들기]
1. 공부할 PDF를 ChatGPT 채팅에 업로드합니다.
2. 아래 문장을 복사해서 ChatGPT에 말합니다.

   이 PDF 내용을 바탕으로 쉬운 객관식 문제 정확히 10개 만들어 줘.
   문제는 자료에서 확인할 수 있는 내용으로 만들고 각 문제에 보기 4개,
   정답 인덱스(answerIndex: 0, 1, 2, 3 중 하나)와 해설을 포함해 줘.
   반드시 아래 형식의 JSON만 출력해 줘.
   {"title":"PDF 학습 퀘스트","questions":[{"question":"문제","options":["보기1","보기2","보기3","보기4"],"answerIndex":0,"explanation":"해설"}]}
   questions 배열에는 반드시 실제 문제 10개를 넣어 줘.

3. ChatGPT가 작성한 JSON을 복사해 게임의 '문제 JSON 붙여넣기'에 붙여넣습니다.
4. '붙여넣은 문제로 시작'을 누릅니다.
   또는 ChatGPT에게 .json 파일을 만들어 달라고 요청한 후 그 파일을 게임에서 선택합니다.

[게임]
- 정답: 몬스터 HP -25, 경험치 +10, 코인 +2
- 몬스터 처치: 보너스 경험치 +20, 코인 +10
- 틀린 문제: 오답 노트에 자동 저장
- 10문제를 끝내면 오답 다시 풀기 가능
- 복습 정답: 오답 노트에서 제거, 경험치 +5, 코인 +1
- 플레이 기록은 사용 중인 브라우저에 자동 저장
- 전체 초기화 버튼으로 모든 기록 삭제

[주의]
- 이 버전은 PDF를 웹사이트 안에서 직접 분석하지 않습니다.
  PDF 분석과 문제 생성은 ChatGPT 채팅에서 하고,
  게임에는 그 결과(JSON)를 가져오는 방식입니다.
- 따라서 별도 OpenAI API 키, .env 파일, Node.js 서버, 결제 설정은 필요하지 않습니다.
- 전에 노출된 API 키가 있다면 API 키 관리 페이지에서 폐기하세요.
- 새로운 문제를 불러오면 진행 중이던 문제 세트와 오답 노트는 초기화됩니다.
  레벨/코인 등 캐릭터 성장 기록은 유지됩니다.
